# Lunas Backup pour Home Assistant

Dépôt d’apps Home Assistant pour Lunas Backup,
un outil de sauvegarde auto-hébergé.

## Ajouter le dépôt

*Paramètres → Applications → Boutique d'applications → ⋮ → Dépôts*, puis
ajoute :

```
https://github.com/mdespeuilles/lunas-backup-ha
```

## Apps

- **Lunas Backup Agent** : envoie les sauvegardes de Home Assistant vers un S3.
  Prend en charge `amd64` et `aarch64` (Raspberry Pi 4/5, Home Assistant Green
  et Yellow).
